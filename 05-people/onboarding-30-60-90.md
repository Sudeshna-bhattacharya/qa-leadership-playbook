# 30-60-90 Day Onboarding: QA Engineer

Goal: by day 90 the new engineer owns quality for a squad area, contributes to automation independently, and feels part of the team.

## Before day 1

- [ ] Accounts and access ready: repo, CI, test management, environments, chat
- [ ] Buddy assigned (a peer, not their manager)
- [ ] Laptop set up with a script or guide that gets the test suite running in under an hour
- [ ] First-week calendar shared

## Days 1–30: Learn

**Focus:** the product, the people, the way we work.

- [ ] Product walkthrough with a PO; use the product as a customer
- [ ] Read the [test strategy](../01-strategy/test-strategy-template.md), [QA in Agile](../02-process/qa-in-agile.md) and [coding standards](../03-automation/coding-standards.md)
- [ ] Run the full automation suite locally and in CI; read a failing report
- [ ] Shadow story testing and a triage session
- [ ] Pair on 2–3 stories with their buddy
- [ ] **First PR:** fix a small test, a flaky test or docs
- [ ] One exploratory session with a charter; debrief with the lead

**Check-in at 30 days:** What's confusing? What would you change? (Fresh eyes are valuable, so write it down.)

## Days 31–60: Contribute

**Focus:** independent delivery with support.

- [ ] Test stories end to end in one squad, with buddy review
- [ ] Attend Three Amigos and contribute examples and edge cases
- [ ] Add API and UI automation for their own stories
- [ ] Raise well-structured bugs; join triage
- [ ] Review at least 3 test PRs from others

**Check-in at 60 days:** agree a growth goal from the [skills matrix](skills-matrix.md).

## Days 61–90: Own

**Focus:** ownership and improvement.

- [ ] Owns QA for a squad area or feature, including risk assessment and test plan input
- [ ] Leads a bug bash or exploratory session
- [ ] Delivers one improvement: e.g. a flaky-test fix, new test data builder, faster pipeline step, documentation gap
- [ ] Presents something learned in a team knowledge-share

**Review at 90 days:** strengths, growth areas, goals for the next quarter.
