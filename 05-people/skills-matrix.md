# QA Skills Matrix

Used for growth conversations, not performance scoring. Engineers self-assess, the lead adds a view, and together they pick **one or two** areas to grow each quarter.

**Levels:** 1 = Learning · 2 = Practising with support · 3 = Independent · 4 = Teaches others / sets direction

## Competencies

| Area | Associate | QA Engineer | Senior QA | Lead / Principal |
|---|---|---|---|---|
| **Test design** | Writes test cases from acceptance criteria | Uses techniques (boundaries, equivalence, state, pairwise) | Designs risk-based approaches for complex features | Defines test strategy across products |
| **Exploratory testing** | Follows charters | Writes own charters; finds non-obvious bugs | Coaches others; runs bug bashes | Builds an exploratory culture |
| **API testing** | Sends requests, checks status codes | Chaining, auth, schema validation, negatives | Designs API test suites and contract tests | Sets API quality standards across teams |
| **UI automation** | Edits existing tests | Writes stable tests following standards | Designs frameworks, fixtures, CI integration | Chooses tools; owns automation architecture |
| **Performance** | Understands concepts | Runs existing k6/JMeter scripts, reads results | Designs load models, finds bottlenecks | Defines performance strategy and SLOs |
| **Accessibility** | Knows WCAG basics | Runs axe/Lighthouse, keyboard checks | Screen-reader testing; trains devs | Embeds a11y into design and Definition of Done |
| **CI/CD** | Reads pipeline results | Adds tests to pipelines | Optimises pipelines (parallelism, sharding) | Designs quality gates end to end |
| **AI-assisted testing** | Uses AI to draft test ideas | Uses AI for data, code and triage, verifying every output | Builds team prompts and workflows | Sets AI usage guidelines and guardrails |
| **Collaboration** | Asks good questions | Effective in Three Amigos | Influences developers and Product on quality | Shapes engineering culture |
| **Leadership** | Owns own tasks | Mentors new joiners | Leads quality for a squad | Leads and grows QA teams; hiring |

## Quarterly growth conversation

1. Self-assessment and lead assessment, side by side
2. Celebrate one strength
3. Pick 1–2 growth areas, with a concrete project for each (e.g. "add performance tests for the search API")
4. Agree support: pairing, course, time allocation
5. Review progress at the next 1:1s, not only at quarter end
